# Фаза 7. Результаты: независимая проверка, обобщение, честное сравнение

`PHASE7_RESULTS.md`, `PHASE7_NUMERICAL_VALIDATION.md`, `PHASE7_NOVELTY_ASSESSMENT.md`,

**Задача.** Гладкий двойной гауссов барьер
V(x) = V_L·exp(−(x + d/2)²/s²) + V_R·exp(−(x − d/2)²/s²), s = 0,6, d = 4, ħ²/2m = 1. Параметры
μ = (E, V_L, V_R) лежат в области [0,1; 10] × [8; 12]². Для экстраполяции используются отдельные
области с высотами 12–14 и 6–8. Эталоном служит МКЭ (P1, h = 0,0025, N = 4331 узел, точные
прозрачные граничные условия).

## Кратко для научного руководителя

1. **Физика проверена независимо (H1 подтверждена).** МКЭ сходится к решению ОДУ (DOP853, без
   сетки) со вторым порядком: отношение ошибок при уменьшении h вдвое равно 3,93–4,01 на шести
   сетках. На рабочей сетке ошибка t составляет 4·10⁻⁵–2·10⁻⁴, положение резонанса определено
   точнее 0,65 % ширины Γ. Все резонансы — устойчивые полюса t: они не исчезают и не появляются
   при измельчении сетки, увеличении области и энергетической сетки. Артефактов не найдено. Грубая
   энергетическая сетка может *пропустить* узкий резонанс, но ложных пиков не создаёт ни одна сетка.
2. **Проекционный RB обобщает, чисто данные-ориентированные методы — нет (H2 подтверждена).** В
   трёхпараметрической задаче (параметры E, V_L, V_R; пространство одномерно) RB-Галёркин даёт max |Δt| = 1,2·10⁻⁹ на 1024 тестовых точках при 48 решениях
   МКЭ и 5,7·10⁻⁴ при 24 решениях. RBF-интерполяция t, регрессия POD-коэффициентов и
   MLP (PyTorch, до 4096 обучающих точек) остаются на уровне ошибки ~1. Ни один из этих методов не
   разрешил ни одного тестового резонанса. Аудит показал, что MLP был недообучен. После подбора
   только на валидации (256 × 3, 10 000 эпох) его средняя ошибка |ΔT| — 2,6–3,5·10⁻³ вместо 9,1·10⁻³.
   Наибольшая ошибка остаётся 0,39–0,63 — у узких резонансов, где сеть не воспроизводит даже свои
   обучающие точки (`docs/audit/ML_EVALUATION_AUDIT.md`).
3. **Жадный отбор не всегда лучше плана Соболя.** По max |Δt| при n ≥ 20 они примерно равны. Жадный
   отбор выигрывает в разрешении резонансов при малом n: при n = 16 доля разрешённых резонансов
   1,00 против 0,61. Галёркин точнее LSPG при всех бюджетах.
4. **Экстраполяция (H3).** При промежуточных бюджетах RB теряет примерно в 3 раза
   (n = 24: 2,0·10⁻³ против 5,7·10⁻⁴), при n = 48 не теряет ничего. Средняя ошибка MLP вне
   области обучения растёт в 13 раз.
5. **Перенос базиса удачнее ожиданий (H4 частично опровергнута).** Базис только из решений для
   *прямоугольных* барьеров (48 снимков) даёт на гауссовой задаче 1,2·10⁻⁴, то есть ошибку
   дискретизации самого МКЭ. Ему нужен примерно вдвое больший размер, чем родному базису. Добавление
   8 гауссовых снимков даёт 1,5·10⁻⁷. Это проверено для одной пары семейств на общей сетке.
6. **Размер базиса определяется числом резонансов, а не их шириной (H5 подтверждена).** При
   фиксированной геометрии каждый резонанс в энергетическом окне добавляет 1,5–3 базисные функции.
   Сужение самого узкого резонанса в 160 раз добавляет не более одной. Ширина сказывается иначе:
   достижимая в двойной точности ошибка ≈ 5·10⁻¹¹/Γ_min (19 геометрий, разброс в 3 раза). Поэтому
   точности 10⁻⁶ и 10⁻⁸ при очень узких резонансах недостижимы по причине округления, а не размера
   базиса.
7. **Гарантированная оценка ошибки верна всегда, но груба у резонансов (H6 подтверждена).**
   ‖e_ψ‖ ≤ ‖невязка‖/σ_min(A); σ_min вычисляется точно, через ленточную задачу Голуба–Кахана с запасом
   на округление. Оценка выполнена в 100 % случаев (326 точек × 4 базиса). Медианное завышение
   составляет 28–57 раз в случайных точках и 95–400 раз в окрестности ±2Γ резонансов. Оценка
   ‖A⁻¹‖ степенным методом (фаза 6) занижена до 3,4 % и гарантией служить не может. σ_min считается
   на полной модели для каждой точки, поэтому это апостериорный сертификат, а не «быстрая»
   сертифицированная RB-оценка.
8. **Одна энергетическая линия.** RB выходит на предел точности (~7·10⁻⁸) за 16 запросов,
   адаптивный AAA — за 24, AAA на равномерной сетке — примерно за 48. PCHIP не справляется ни при
   каком бюджете до 64. Это ожидаемо: Галёркин-RB на линии сам является рациональной функцией k.
9. **Устойчивость.**
   - Шум 10⁻¹⁰ портит AAA на равномерной сетке до 4·10⁻⁴.
   - Адаптивный AAA устойчивее всех (ошибка ≈ 20–70 σ), RB на зашумлённых снимках даёт ≈ 400–800 σ.
   - Почти вырожденные дублеты (расщепление 0,16 Γ, тройной гауссов барьер) RB разрешает при всех
     бюджетах, адаптивный AAA — с n = 24.
   - Снимки с грубой сетки, спроецированные на точный оператор, улучшают результат лишь немного.
10. **Стоимость.** Одиночный запрос RB (n = 24) занимает 79 мкс, против 360 мкс у МКЭ. С учётом
    жадного отбора RB окупается после ~6800 запросов (после ~570 с планом Соболя). Ступенчатая
    S-матрица с точностью МКЭ требует M = 4000 слоёв: 0,13 с на энергию при поштучных вызовах и
    0,5 мс в пакетном режиме. Ускорения для малых объёмов вычислений нет.

## Новизна (подробно: `PHASE7_NOVELTY_ASSESSMENT.md`)

**Открытия нет, новых методов нет.**
- Жадные Галёркин/LSPG-эмуляторы для квантового рассеяния опубликованы (Maldonado, Drischler,
  Furnstahl, Mlinarić, Phys. Rev. C 112, 024002, 2025).
- Связь рациональной интерполяции с проекционными методами известна (Pradovera и соавт.).
- Грубость оценок с невязкой у резонансов известна (Sen et al., 2006).

Вклад работы — учебного уровня: независимо проверенный бенчмарк на гладком потенциале,
сравнение методов без утечки тестовых данных при равном числе запросов и развязанное по факторам
исследование размера базиса. Полные тексты ближайших работ из среды были недоступны; проверка
сделана по аннотациям и индексам.

## Протокол без утечки

- У каждого множества свой seed: кандидаты, валидация, тест, тест вне области, сканы, планы.
  SHA-256 параметров записаны в манифест.
- Ядро RBF и гиперпараметры MLP выбраны **только на валидации**.
- Данные-ориентированные методы показаны только на заранее объявленном плане (Соболь).
- Ограничение фазы 6 (план для RBF/POD там выбирался по тестовым данным) зафиксировано в
  `PHASE7_LIMITATIONS.md` §5 и здесь не повторено; артефакты фазы 6 не изменялись.
