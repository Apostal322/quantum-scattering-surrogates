# Фаза 6: обзор литературы (проверено 20.10.2026)

**Ограничения проверки.** Из среды, где выполнялась фаза 6, недоступны arxiv.org, export.arxiv.org,
zenodo.org и сайты журналов (DNS-ошибка; инструмент загрузки страниц отклоняет запросы). GitHub
доступен только через анонимный git-прокси. Поэтому для каждого источника указан **уровень
проверки**:

| Уровень | Значение |
|---|---|
| **V-code** | Репозиторий склонирован и просмотрен нами (файлы, коммит, лицензия). |
| **V-index** | Название, авторы, дата и содержание на уровне аннотации подтверждены по поисковым индексам страниц arXiv/APS/SciPost. **Полный текст не прочитан.** |
| **NOT FOUND** | Идентификатор не удалось сопоставить ни с одним проиндексированным документом; содержание не описываем. |

Приводимые числа — **утверждения авторов** (из аннотаций и фрагментов), а не воспроизведённые нами
результаты.
